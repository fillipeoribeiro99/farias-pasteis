# Farias Pastéis | Landing Page

**Landing Page Responsiva | HTML5 • CSS3 • JavaScript**

Projeto de desenvolvimento front-end de uma landing page para a **Farias Pastéis**, com foco na apresentação dos produtos, experiência do usuário e direcionamento de clientes para a loja oficial no iFood.

O site foi desenvolvido com abordagem **Mobile First**, priorizando a navegação em dispositivos móveis, a organização visual do cardápio e a facilidade de acesso aos pedidos.

## Objetivo do Projeto

Desenvolver uma presença digital moderna, atrativa e funcional para a Farias Pastéis, oferecendo aos clientes uma maneira simples de conhecer os produtos e acessar o canal oficial de vendas.

A solução foi planejada para unir identidade visual, responsividade, usabilidade e praticidade, proporcionando uma navegação intuitiva.

## Funcionalidades

- **Cardápio digital:** apresentação de 12 sabores de pastéis, com fotografias e nomes dos produtos.
- **Filtros por categoria:** visualização de todos os produtos, pastéis salgados e doces.
- **Busca interativa:** pesquisa de sabores com atualização dinâmica dos resultados.
- **Integração com iFood:** botões que direcionam os clientes para a loja oficial.
- **Design responsivo:** interface adaptada para smartphones, tablets e computadores.
- **Navegação mobile:** menu compacto e elementos adaptados para telas menores.
- **Botão fixo de pedido:** acesso rápido ao iFood durante a navegação.
- **Identidade visual personalizada:** utilização da logo oficial e das cores vermelho e amarelo da marca.

## Desenvolvimento Mobile First

O projeto foi estruturado priorizando dispositivos móveis, considerando a praticidade e a facilidade de navegação para os clientes.

A interface conta com cardápio adaptável, botões de fácil acesso, navegação simplificada e organização visual que favorece a visualização dos produtos.

## Como Executar o Projeto

1. Clone o repositório ou baixe os arquivos.
2. Abra a pasta no Visual Studio Code.
3. Execute o arquivo `index.html` diretamente no navegador ou utilize a extensão Live Server.
4. Explore o cardápio, utilize os filtros e teste os botões de direcionamento ao iFood.

O projeto utiliza tecnologias front-end e não necessita de backend ou banco de dados.

## Integração com o iFood

A landing page funciona como uma vitrine digital da Farias Pastéis.

Ao clicar nos botões de pedido, o usuário é direcionado para a página oficial da pastelaria no iFood, onde poderá consultar os preços, verificar a disponibilidade e finalizar a compra.

O site não processa pagamentos ou pedidos diretamente.
